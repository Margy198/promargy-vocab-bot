# Promargy Vocab Bot

Telegram-бот: квиз на 4 варианта перевода, кнопки под сообщением, счёт и серия правильных
ответов, слова с ошибками попадаются чаще. Загружено 379 слов/фраз из твоего файла —
и в любой момент можно добавлять новые прямо из чата с ботом, без редеплоя (см. ниже).

Работает как serverless-функция на Netlify (как и schedule.promargy.com) — отдельный
сервер не нужен, состояние (счёт, прогресс) хранится в Netlify Blobs автоматически.

## Шаг 1. Создать бота в Telegram

1. Открой в Telegram [@BotFather](https://t.me/BotFather).
2. `/newbot` → придумай имя и юзернейм (должен заканчиваться на `bot`, например `promargy_vocab_bot`).
3. BotFather пришлёт **токен** вида `123456:AAExxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx` — сохрани его,
   он понадобится в шаге 3.

## Шаг 2. Задеплоить на Netlify (без GitHub — так же, как твои прошлые сайты)

Твои текущие проекты на Netlify задеплоены через drag-and-drop ("Netlify Drop"), не через
GitHub — этот бот настроен именно под такой способ. `node_modules` уже включён в архив
специально для этого: при обычной загрузке файлов Netlify не запускает `npm install` сама,
поэтому зависимость `@netlify/blobs` должна лежать в архиве заранее.

1. Открой [app.netlify.com](https://app.netlify.com) → **Projects**.
2. Перетащи содержимое архива (папку `promargy-vocab-bot` — то, что внутри .zip) в область
   "Drag and drop your folder here" внизу страницы (или "Add new project" → тот же способ).
   Если Netlify не даёт перетащить папку — можно просто занести сам .zip-файл, она распакует его сама.
3. Дождись, пока статус деплоя станет зелёным (Published). Открой карточку проекта —
   там будет адрес вида `https://<случайное-имя>.netlify.app`.
4. Переименуй сайт для удобства: **Site configuration → General → Change site name**.

### Если позже захочешь автообновление через GitHub

Это удобнее, когда часто добавляешь новые слова: пушишь в репозиторий — сайт передеплоивается
сам, без повторного перетаскивания архива. Тогда `node_modules` из архива можно убрать —
Netlify соберёт зависимости сама:

```bash
cd promargy-vocab-bot
git init && git add . && git commit -m "Initial vocab bot"
git branch -M main
git remote add origin https://github.com/Margy198/promargy-vocab-bot.git
git push -u origin main
```

Дальше в Netlify: **Add new project → Import an existing project** → выбрать репозиторий.

## Шаг 3. Переменные окружения

В карточке сайта: **Site configuration → Environment variables → Add a variable** → добавь по одной:

- `TELEGRAM_BOT_TOKEN` — токен из шага 1
- `TELEGRAM_WEBHOOK_SECRET` — любая случайная строка, которую ты сама придумываешь
  (например, `openssl rand -hex 20` в терминале, или просто набор случайных символов).
  Она защищает вебхук от чужих запросов — Telegram у BotFather её не выдаёт.

После добавления переменных передеплой сайт ещё раз (перетащи ту же папку/архив заново) —
так функция точно подхватит новые значения.

## Шаг 4. Подключить вебхук (один раз)

Выполни в терминале, подставив свой токен, секрет и адрес сайта:

```bash
curl -X POST "https://api.telegram.org/bot<ТВОЙ_ТОКЕН>/setWebhook" \
  -H "Content-Type: application/json" \
  -d '{
    "url": "https://<ТВОЙ-САЙТ>.netlify.app/telegram-webhook",
    "secret_token": "<ТВОЙ_TELEGRAM_WEBHOOK_SECRET>"
  }'
```

Ответ `{"ok":true,...}` значит, что всё подключилось.

## Шаг 5. Проверить

Открой своего бота в Telegram → `/start`. Дальше:
- `/play` — новый вопрос
- `/score` — статистика (счёт, серия, топ слов с ошибками)
- `/count` — сколько слов в словаре
- `/delete <English word>` — удалить слово
- `/reset` — сбросить прогресс
- `/help` — список команд
- просто вставь строки «English . перевод» — чтобы добавить новые слова

## Как добавлять и удалять слова (без редеплоя!)

Теперь это самое простое: просто пиши боту в Telegram.

- **Добавить слова** — вставь в чат одну или сразу много строк вида:
  ```
  English . перевод
  Ещё одно слово . ещё перевод
  ```
  Можно прямо кусок сырых заметок с урока, как тот файл, что ты присылала изначально —
  бот сам разберёт строки, пропустит дубли и то, что не похоже на пару, и напишет,
  сколько добавил.
- **Удалить слово** — `/delete English word`
- **Посмотреть, сколько слов сейчас в базе** — `/count`

Ничего никуда перетаскивать не нужно — изменения применяются сразу же, слово может
попасться в следующем вопросе. `data/vocab.mjs` в архиве — это только стартовый набор
из 379 слов, который загружается один раз при самом первом запуске бота; дальше бот
работает со своей копией словаря в Netlify Blobs, а не с этим файлом.

## Мини-приложение (Telegram Mini App)

Страница `public/app/index.html` открывается прямо внутри Telegram: прогресс, словарь по папкам, лига, блиц и настройки. Данные берёт через POST на `/telegram-webhook` с `initData` (подпись проверяется на сервере, доступ — только у одобренных учеников).

Что нужно один раз:

1. Задеплоить (адрес сайта Netlify подставляет сам через `URL`; если хочешь другой адрес — переменная `MINI_APP_URL`). После этого у всех появится кнопка «📱 Приложение» в нижней клавиатуре (после `/start`).
2. Чтобы приложение открывалось и из кнопки меню слева от поля ввода — отправь боту `/appbutton` (команда для админа).
3. Необязательно: в @BotFather → `/mybots` → бот → Bot Settings → Menu Button можно поставить тот же адрес `https://<сайт>/app/`.

Открыть страницу в обычном браузере тоже можно — она покажет демо-данные (удобно смотреть дизайн).

### Курс A0–C1 внутри приложения (вкладка «Учёба»)

Контент курса берётся из Notion-плана «Твой путь в английский» и лежит в `data/course/` (`index.json` + `topics/<id>.json`). Его не редактируют руками — он собирается скриптом:

1. Выгрузить темы из Notion в `content-export/` (сырой текст страниц + `index.json` со списком тем по уровням).
2. `python3 scripts/build-course.py /путь/к/content-export` — пересобирает `data/course/`.
3. Закоммитить и задеплоить.

Прогресс ученика по темам и его заметки хранятся в Blobs-хранилище `vocab-bot-course`. За пройденную тему начисляется 50 XP.

### «Мои темы» — предложения по интересам ученика

Готовый банк: `data/interests/<key>.json` (40 тем × 24 предложения A2/B1/B2, у каждого — перевод и 2 слова с переводом). Проверка и сборка индекса: `python3 scripts/check-interests.py`.

Свои темы ученика генерируются фоновой функцией `interest-generate-background` через Anthropic API. Чтобы включить, добавь в Netlify переменные окружения:

- `ANTHROPIC_API_KEY` — ключ с console.anthropic.com (одна тема ≈ 1 запрос, копейки);
- `ANTHROPIC_MODEL` — необязательно, по умолчанию `claude-sonnet-5-5`.

Без ключа свои темы сохраняются со статусом «генерация выключена», а готовые 40 тем работают всегда. Результаты генерации лежат в Blobs `vocab-bot-course` под ключами `interest:custom:<slug>` и общие для всех учеников с одинаковой темой.

### Кабинет учителя и домашка

Открывается только у админов бота (те, кто сделал `/claim`): вкладка «Учёба» → карточка «Кабинет учителя» (или кнопка под `/students`). Там:

- список учеников по последней активности: серия, XP за неделю, пройденные темы, слов в словаре, статус домашки; поиск по имени;
- карточка ученика: две недели активности, точность, темы курса (пройдено / в процессе), частые ошибки в словаре, победы, домашка; кнопка «Написать в Telegram»;
- «Задать домашку» — одному ученику или сразу нескольким/всем: тема курса (поиск по названию), срок (3 дня / неделя / 2 недели / дата / без срока), комментарий. Ученику приходит сообщение в чат с кнопкой «Открыть домашку».

У ученика домашка — первая карточка на вкладке «Учёба» и отдельный экран «Домашка» (сделать / сдано, просрочка подсвечена). Домашка считается сданной, когда ученик нажимает в теме «Тема пройдена ✓» — тебе приходит ✅ в чат. Напоминания ученику: за день до срока и в день срока (вместе с остальными напоминаниями по cron `?remind=`). Хранится в Blobs `vocab-bot-course` под ключом `hw:<chatId>`.

### Пересборка курса и заданий из Notion — без кода

Кабинет учителя → «🛠 Контент». Один раз нужно подключить Notion:

1. На https://www.notion.so/my-integrations создай внутреннюю интеграцию (Internal), скопируй токен (`ntn_…`/`secret_…`).
2. Открой страницу плана «📘 Твой путь в английский» → меню ⋯ → «Подключения» (Connections) → добавь интеграцию. Доступ наследуется всеми подстраницами уровней и тем.
3. В Netlify → Site configuration → Environment variables добавь `NOTION_TOKEN` = токен, нажми Redeploy.

Дальше:

- **Пересобрать курс из Notion** — фоновая функция `course-rebuild-background` читает страницы A0–C1 под планом (по одному уровню за вызов, вызывая себя дальше), разбирает их той же логикой, что `scripts/build-course.py` (общий модуль `netlify/lib/course-builder.mjs`), и кладёт результат в Blobs `vocab-bot-course`: `course:level:<код>`, `course:topic:<id>`, `course:index`, `course:meta`. Бот и приложение берут контент оттуда, если он есть, иначе — встроенный бандл `data/course`. Прогресс учеников хранится отдельно и не трогается. Структура страницы темы та же, что сейчас: `## 🎯 Зачем эта тема`, `## 📖 Теория` (подразделы `###` становятся страницами), `## ⚠️ Подводные камни`, `## ✍️ Упражнения` (`### Упражнение N. …` + toggle «Ответы»), `## 🔗 Дополнительная практика`, `## ✅ Самопроверка` (чекбоксы). На странице уровня темы перечислены как `## N. [эмодзи Название](ссылка)` + курсивом описание + «**В теме:** …». Уровень, который не удалось прочитать, остаётся прежним (статус «готово с замечаниями»).
- **Создать базу заданий в Notion** — создаёт под планом базу «Задания бота» и переносит туда все встроенные задания at/in/on, условных и герундия (колонки: Предложение с `___`, Тип, Вариант 1–3, Верный (1–3), Объяснение, Активно). Id базы сохраняется в Blobs `grammar:dbId` (можно задать и переменной `NOTION_GRAMMAR_DB`).
- **Пересобрать задания** — читает базу и пишет `grammar:items`; бот берёт оттуда тип, в котором ≥ 5 заданий, иначе встроенные из `data/grammar-extra.mjs`. Неправильные строки (нет `___`, не 3 варианта, «Верный» не 1–3) пропускаются и перечисляются в журнале.
- **Вернуть встроенную** — удаляет версию из Blobs.

Статус и журнал последней пересборки видны на том же экране (`rebuild:status`). Если переменной `NOTION_COURSE_ROOT` нет, корнем считается страница плана `34c2f2f8690d814e82e8fb81e078333e`.

### Режим «вспоминаю сама» (без вариантов ответа)

По умолчанию бот даёт варианты ответа кнопками. Команда `/recall` (или переключатель «Вспоминать самой» в приложении → Аккаунт) включает режим, в котором вместо вариантов показывается одна кнопка «🔎 Показать ответ»: ученик сначала вспоминает сам, потом открывает верный ответ (с объяснением правила, если оно есть) и отмечает «✅ Знал(а)» или «❌ Не знал(а)». Засчитывается обычным путём: «Знал» уходит как ответ на верную позицию, «Не знал» — как `a:-1`, поэтому статистика, серия, XP и интервальные повторения считаются так же, как при выборе варианта. Настройка живёт в `identity.recallMode`, работает во всех режимах бота (лексика, грамматика, неправильные глаголы, идиомы).

### Чем открывать приложение (важно)

Telegram передаёт мини-приложению данные пользователя (`initData`) при запуске **inline-кнопкой**, **кнопкой меню**, по прямой ссылке и из меню вложений — но **не передаёт их для кнопки обычной клавиатуры** (`KeyboardButton.web_app`). Раньше «📱 Приложение» было именно такой кнопкой, поэтому у всех учеников приложение считало себя открытым в браузере и показывало демо-данные.

Теперь «📱 Приложение» на клавиатуре — обычная кнопка: по ней (и по команде `/app`) бот присылает сообщение с inline-кнопкой «Открыть тренажёр». Все остальные кнопки приложения (домашка, напоминания, `/students`) и так inline. `/appbutton` ставит кнопку меню — она тоже передаёт данные.

### Вход в приложение, если Telegram не передал данные пользователя

Обычно Telegram сам сообщает приложению, кто его открыл (`initData`). На части устройств (видели на iOS) при запуске приходят только версия, платформа и тема, а данные пользователя — нет; тогда приложение раньше считало себя открытым в обычном браузере и показывало демо-словарь.

Теперь есть запасной вход: бот добавляет в адрес кнопки подпись `?t=<chatId>.<срок>.<HMAC>` (HMAC на `TELEGRAM_WEBHOOK_SECRET`, срок — 30 дней). Приложение сохраняет её и отправляет вместо `initData`, сервер проверяет подпись и срок (`verifyAppToken`). Ссылка живёт только в личном чате с этим учеником; подделать её нельзя, просроченную и чужую сервер отклоняет. Если срок вышел — достаточно открыть приложение заново кнопкой из бота, токен обновится.

### Мгновенный старт, офлайн и тёмная тема

Приложение кэширует на телефоне профиль, список курса, словарь и последние 40 открытых тем (localStorage), поэтому открывается сразу и показывает теорию без сети (с пометкой «показана сохранённая копия»). Тёмная тема включается автоматически по настройке Telegram.

### Тренировка по упражнениям курса

Каждый пункт упражнения из Notion превращается в интерактивное задание (`netlify/lib/drill-builder.mjs`, строится при отдаче темы, поэтому всегда совпадает с текущим текстом в Notion):

- **выбор** — варианты из самого задания («(has / have)», «a) … b) …», название «ever или never», условные обозначения «У — умение, П — просьба»), формы глагола только неверные (`goed`, `has be`), артикли a / an / the / без артикля по набору упражнения; правильный ответ всегда из ключа Марго;
- **собери из слов** — переводы и трансформации целым предложением, в пропусках — только пропущенные слова (+ ловушки вроде `do / does`);
- **впиши** — короткий ответ в пропуск; не совпало с ключом — приложение показывает ключ и дает засчитать свой вариант («Ответ никогда не врет»);
- **вспомни** — где вариантов честно не построить; творческие задания («о себе») показывают пример ответа.

В теме есть «🎯 Тренировка» — 20 заданий вперемешку из всех упражнений, ошибки повторяются в конце. Режим «вспоминаю сама» (Аккаунт) работает и здесь.
Проверка: `node scripts/lint-drills.mjs` — [A] брак конвертера (должно быть 0), [B] вопросы к содержанию в Notion.

### Курс «для работы» (бизнес-версия плана)

Переключатель «📘 Обычный / 💼 Для работы» на главной «Учебы» появляется, когда бизнес-план собран: Кабинет → 🛠 Контент → «💼 Курс для работы» → «Собрать из Notion». Перед первой сборкой на странице «Бизнес-английский — самостоятельный план» → ⋯ → «Подключения» добавь ту же интеграцию. Данные лежат в Blobs `biz:*`, уровень и прогресс у версий свои (в бизнес-версии нет A0). Корень можно сменить переменной `NOTION_BUSINESS_ROOT`.

## Технические детали (на будущее, если понадобится что-то поменять)

- `netlify/functions/telegram-webhook.js` — вся логика бота.
- `data/vocab.mjs` — стартовый набор слов, используется только один раз при первом запуске.
- Рабочий словарь и состояние (счёт, текущий вопрос) хранятся в Netlify Blobs — отдельно
  на каждый chat_id для прогресса, и один общий список для словаря. Работает "из коробки"
  на Netlify, ключей заводить не нужно.
- Формат отправки: quiz-вопрос → 4 кнопки (`inline_keyboard`) → нажатие кнопки шлёт
  `callback_query` на тот же вебхук → бот проверяет ответ и сразу присылает следующий вопрос.
