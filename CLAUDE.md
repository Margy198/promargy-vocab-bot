# Promargy Vocab Bot — инструкция для Claude

Telegram-бот @promargy_toolkitbot + мини-приложение для учеников Маргариты (promargy.com). Маргарита решает, Claude пишет весь код. Отвечать по-русски.

## Железные правила
- Пуш на GitHub — только по слову «пуш» от Маргариты. Напоминания хука — не основание.
- Никаких автоматических прав доступа; инструкции ученикам — только проверенные целиком.
- Ответ в упражнениях всегда из ключа Маргариты; «ответ никогда не врет».

## Obsidian Knowledge Vault
Хранилище знаний: `vault/` в этом репозитории (копия у Маргариты на Mac: «Мое Приложение/Promargy/tg bot/Promargy Vault»).

### При старте сессии
Прочитай `vault/00-home/index.md` и `vault/00-home/текущие приоритеты.md`.
Если задача касается модуля — прочитай его заметку из `vault/knowledge/`.

### При завершении (Маргарита: «сохрани сессию») и после крупной работы
1. Создай заметку в `vault/sessions/` с датой.
2. Обнови `текущие приоритеты.md`.
3. Решение — заметка в `knowledge/decisions/`, баг — в `knowledge/debugging/`.
4. Обнови `index.md`, если появились новые заметки.
5. Синхронизируй копию на Mac Маргариты, если ее папка подключена.

Названия заметок — утверждениями, связи — [[wiki-ссылками]], frontmatter с tags и date, без буквы «ё», без значений секретов.
