# Карта файлов репозитория

- `netlify/functions/telegram-webhook.js` — бот + API приложения
- `netlify/functions/course-rebuild-background.js` — сборка из Notion (курс, бизнес-план, задания)
- `netlify/lib/course-builder.mjs` — markdown Notion → тема (разделы, теория, упражнения, самопроверка)
- `netlify/lib/drill-builder.mjs` — упражнение → интерактивные задания
- `public/app/index.html` — мини-приложение
- `data/course/` — встроенный курс A0–C1 (83 темы), `data/interests/` — 40 тем «Мои темы»
- `data/vocab.mjs`, `data/grammar-extra.mjs` — стартовые слова и задания
- `scripts/build-course.py` — сборка бандла из выгрузки Notion
- `scripts/lint-drills.mjs` — проверка заданий ([A] брак = 0, [B] вопросы к Notion)
- `scripts/check-interests.py` — проверка банка интересов
- `vault/` — эта база знаний
