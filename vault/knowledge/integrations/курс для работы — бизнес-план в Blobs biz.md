# Курс для работы — бизнес-план в Blobs biz

- Источник: Notion «💼 Бизнес-английский — самостоятельный план от A1 до C1» (4022f2f8690d8143b223fce9744efecb). Уровни A1–C1 «… для работы» (A0 нет).
- Сквозные бизнес-блоки (дочерние страницы корня, не уровни: Смягчение, Филлеры, Переписка, Встречи, Переговоры, Словари) → «уровень» `BIZ`, категория «Бизнес-блоки», в приложении подпись «💼 Блоки».
- Сборка: Контент → «💼 Курс для работы → Собрать из Notion» (mode `bizCourse`), ключи `biz:*`. **Нужно** подключить интеграцию Notion к странице бизнес-плана.
- Ответы в бизнес-плане — обычный заголовок `### Ответы к упражнению N {toggle="true"}` + абзац «1. … 2. …»; парсер это понимает.
- Ученик: переключатель «📘 Обычный / 💼 Для работы» (action `courseTrack`), виден только когда `biz:index` есть. Уровень отдельный (`bizLevel`), прогресс по темам общий (id разные).
