# Курс A0–C1 собирается из Notion в Blobs course

- Источник: Notion «📘 Твой путь в английский» (корень 34c2f2f8690d814e82e8fb81e078333e), уровни A0–C1 = дочерние страницы «A1 — …».
- Кнопка: Кабинет → 🛠 Контент → «Пересобрать курс из Notion». Фоновая функция обрабатывает по уровню за вызов и вызывает себя дальше; журнал в `rebuild:status`.
- Разбор (`course-builder.mjs`): `## Теория` (подразделы `###`/`####` → страницы), `## Подводные камни`, `## ✍️ Упражнения` (`### Упражнение N.` + тоггл «Ответы»), `## ✅ Самопроверка` (чекбоксы). Уровень: `## N. [эмодзи Название](ссылка)` + курсив + «В теме:».
- Тогглы-заголовки `<toggle heading="h2">` верхнего уровня считаются разделами (так устроены бизнес-блоки).
- Нет версии в Blobs → встроенный бандл (83 темы).
