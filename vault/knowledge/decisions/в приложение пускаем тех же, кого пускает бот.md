# В приложение пускаем тех же, кого пускает бот

Решение Маргариты 18.11.2026 («пускать всех, кого пускает бот») после случая Анастасии: бот ее пускал, приложение писало «нет доступа».

Было: приложение требовало явную отметку `approved: true` (или ссылку на фразы, или админа). Давние учетные записи без поля `approved` бот считал одобренными, приложение — нет.

Стало (`handleAppApi`): не пускаем только тех, у кого доступ явно закрыт (`approved === false` без `phrasesAccess`), и тех, у кого записи в боте нет вовсе (ни разу не писали боту). Админ проходит всегда.

Это не автоматическая выдача прав: новых учеников по-прежнему открывает только Маргарита (`/approve`) или пригласительная ссылка. См. [[доступ только по приглашению — никаких автоматических прав]].
