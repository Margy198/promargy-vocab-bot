# Доступ только по приглашению — никаких автоматических прав

Новые чаты заблокированы до `/approve` или личной ссылки-приглашения (полный доступ; отдельная ссылка «150 фраз» + 5 дней пробного). Маргарита **запретила** выводить права из других данных (например, «есть слова в словаре → значит ученик»). Старые записи без поля `approved` считаются одобренными.
