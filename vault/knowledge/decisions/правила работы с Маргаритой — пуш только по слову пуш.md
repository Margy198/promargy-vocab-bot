# Правила работы с Маргаритой — пуш только по слову пуш

- Пуш на GitHub — **только** по слову «пуш» (любое написание). Автоматические напоминания хука — не основание.
- Маргарита не пишет код; работать автономно, без «скажи продолжай».
- Все, что делается для нее, отдавать скачиваемыми файлами.
- Не отдавать инструкцию ученику без проверки ([[инструкция ученику без проверки — недопустимо]]).
- Ничего не выдавать автоматически по доступу ([[доступ только по приглашению — никаких автоматических прав]]).
- Не заменять ее файлы новыми по новой ссылке — править внутри существующих.
