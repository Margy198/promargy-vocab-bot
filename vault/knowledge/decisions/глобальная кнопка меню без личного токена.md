# Глобальная кнопка меню без личного токена

`/appbutton` ставит кнопку меню **для всех** — в ее адресе не должно быть личного токена (однажды так ошиблись: любой мог войти под Маргаритой; исправлено). Личная кнопка ставится на `/start` через `setChatMenuButton` с `chat_id`. Генерировать токен для ее аккаунта ради теста нельзя.
