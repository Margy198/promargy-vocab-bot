# Варианты ответа только из исходного слова — 3 варианта

Правила Маргариты: варианты строятся только из слова/ответа этого задания (study → studies / studys), не из соседних пунктов; максимум 3 варианта; нет Past в Present Simple; после ответа — правило. Дистрактор должен быть **заведомо неверным**: не предлагать пассив/прилагательное (`is open`), эмфатическое `did go`, `was/were` после wish/if. См. [[правила упражнений Маргариты — скилы]].
