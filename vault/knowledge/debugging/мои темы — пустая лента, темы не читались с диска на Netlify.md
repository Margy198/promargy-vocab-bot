# «Мои темы» — пустая лента: темы не читались с диска на Netlify

Симптом (24.11, Маргарита: «зависает и тупит»): после выбора тем экран показывает «Пока нет предложений: выбери темы из списка», хотя тема выбрана. Проверено вживую в Telegram Web.

Причина: каталог тем приходит из импорта `index.mjs` (вшит в бандл), а сами предложения читались через `fs` из `data/interests/<key>.json` — на Netlify путь не находился, `readInterestTopic` возвращал null, лента пустая. Локально с файлами все работало, поэтому тесты не ловили.

Исправление: `data/interests/topics.mjs` (генерируется `scripts/build-interests.py`, все 40 тем, 244 КБ) импортируется в функцию, `readInterestTopic` берет оттуда; файлы — запасной путь. При добавлении тем перегенерировать topics.mjs.

Заодно: в приложении `loadInterests`/`loadFeed` при ошибке сети перезапрашивали бесконечно (экран перерисовывался и снова звал API) — теперь показывается «Не удалось загрузить» с кнопкой «Повторить».
