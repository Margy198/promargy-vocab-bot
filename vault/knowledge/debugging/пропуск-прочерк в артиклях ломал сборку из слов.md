# Пропуск-прочерк в артиклях ломал сборку из слов

В ключах «— Moscow», «from — Spain» прочерк = нулевой артикль; он попадал в плитки («I live in — Moscow»), а «Go to — school» превращалось в ввод «school». Решение: для тем/упражнений про артикли — выбор a / an / the / без артикля по набору из названия («A или AN?», «the или —»); правило «X → Y» снимаем только если сразу после X в задании стоит стрелка/тире. Линтер этого не ловил — найдено ручной выборкой.
