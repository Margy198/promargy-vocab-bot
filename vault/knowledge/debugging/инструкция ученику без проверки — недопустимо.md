# Инструкция ученику без проверки — недопустимо

Однажды инструкция «удали слова, добавь заново с #папка» не сработала у ученика — проверяли только чистый случай. Правило: путь ученика проверяется целиком (повторы, неправильный порядок), а бот должен быть терпимым — делать за одно сообщение.
