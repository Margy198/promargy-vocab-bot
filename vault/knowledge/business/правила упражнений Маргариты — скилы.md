# Правила упражнений Маргариты — скилы

Скилы: /eng-exercise-builder, /tense-exercise-validator, /plan-a1-c1, /self-study-plan, /kak-ya.
- Ответ всегда из ключа; «ответ никогда не врет»; «оба / both» не считать ошибкой.
- Контраст, решаемость пункта (контекст, маркер или все варианты в ответе), без повторов, без кальки.
- Нигде нет буквы «ё».
- Отчет в конце с блоком «Вычитка» (исправлено / решение за ней / есть эффективнее).
