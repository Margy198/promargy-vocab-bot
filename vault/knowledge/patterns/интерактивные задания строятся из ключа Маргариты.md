# Интерактивные задания строятся из ключа Маргариты

`netlify/lib/drill-builder.mjs`: каждый пункт упражнения → задание `{id, ex, i, task, q, key, note, type, …}`. На 13.11: 17 703 пункта — выбор 29%, сборка 43%, впиши 11%, вспомни 18%, 301 упражнение целиком.

Типы:
- **choice** — варианты из задания «(a / b)», «a) … b) …», «(а) … (б) …», название упражнения «ever или never» (слитная группа «may/might/could» = один вариант), условные обозначения из вводной («У — умение»); глагольные дистракторы только неверные; артикли a / an / the / без артикля по набору упражнения; «найди ошибку» — исправленное vs исходное предложение.
- **build** — перевод / трансформация целым предложением; пропуск — только пропущенные слова + ловушки (do/does, in/on/at…).
- **type** — короткий ответ ≤4 слов; не совпал → показ ключа и «У меня то же самое ✓».
- **recall** — где честных вариантов нет; `open: true` для творческих («о себе») — пример ответа.

Вводная упражнения (`drillLeads`) показывается над каждым заданием. «🎯 Тренировка» — 20 заданий вперемешку, ошибки повторяются.

Проверка: `node scripts/lint-drills.mjs`. Решения: [[задания строятся при отдаче темы, а не хранятся в бандле]], [[ответ никогда не врет — свой вариант можно засчитать]]. Баги: [[пропуск-прочерк в артиклях ломал сборку из слов]], [[ключ шире ошибки удваивал слова в исправлении]].
