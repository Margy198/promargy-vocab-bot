# Интерактивные задания строятся из ключа Маргариты

`netlify/lib/drill-builder.mjs`: каждый пункт упражнения → задание `{id, ex, i, task, q, key, note, type, …}`. На 13.11: 17 703 пункта — выбор 29%, сборка 43%, впиши 11%, вспомни 18%, 301 упражнение целиком.

Типы:
- **choice** — варианты из задания «(a / b)», «a) … b) …», «(а) … (б) …», название упражнения «ever или never» (слитная группа «may/might/could» = один вариант), условные обозначения из вводной («У — умение»); глагольные дистракторы только неверные; артикли a / an / the / без артикля по набору упражнения; «найди ошибку» — исправленное vs исходное предложение.
- **build** — перевод / трансформация целым предложением; пропуск — только пропущенные слова + ловушки (do/does, in/on/at…).
- **type** — короткий ответ ≤4 слов; не совпал → показ ключа и «У меня то же самое ✓».
- **recall** — где честных вариантов нет; `open: true` для творческих («о себе») — пример ответа.

Вводная упражнения (`drillLeads`) показывается над каждым заданием. «🎯 Тренировка» — 20 заданий вперемешку, ошибки повторяются.

Проверка: `node scripts/lint-drills.mjs`. Решения: [[задания строятся при отдаче темы, а не хранятся в бандле]], [[ответ никогда не врет — свой вариант можно засчитать]]. Баги: [[пропуск-прочерк в артиклях ломал сборку из слов]], [[ключ шире ошибки удваивал слова в исправлении]].

## Пропуск с подсказкой — всегда выбор, не поле ввода (24.11.2026)

Маргарита: «I rent out … flat (I + OWN)» должно давать варианты my own / I own / own / me own, а не поле «Твой ответ». `hintDistractors(ans, hint)` в drill-builder: варианты из подсказки как есть («I own», «own»), формы местоимений (my → me / mine / I), замены служебных слов (in/on/at, some/any, a/the, for/since, much/many…). Срабатывает, когда формы глагола (verbDistractors) дали меньше двух вариантов, и в `typeDrill` перед тем, как отдать поле ввода. До 4 вариантов. Не применяется к трансформациям со стрелкой и ответам длиннее 3 слов — там сборка из слов. Подсказка с русским текстом вариантом не становится, a ↔ an не меняем («an piece» — мусор).

Итог по курсу: выбор 32% → 40%, впиши 11% → 9%, брак по линту 0.

## Каждое задание из Notion — кнопки, не текст (24.11.2026)

Французская страница «произношение: правила чтения» у ученицы Маргариты показывалась простым текстом: формат не «Упражнение N», а блоки `## БЛОК 1.` + жирные подзаголовки `1.1. Выбери…` и один ключ `## КЛЮЧИ` с «<b>1.1.</b> роб / рю / …». Что добавлено:
- **homework-normalizer**: заголовки `N.N.` (жирные или `###`), блоки `## БЛОК N. …` (название блока — вводная упражнения), ключи `<b>N.N.</b> a / b / c<br>…` разносятся по упражнениям; список слов через « / » + ключ через « / » → нумерованные пункты; ключ-подмножество («выпиши только те, где…») → по слову «да / нет».
- **drill-builder**: пункт «robe — роб / робэ» с ключом среди вариантов → выбор; короткие ответы одной письменности без вариантов → варианты из соседних ответов упражнения (`src: "sib"`, до 3 лишних); буквы в названии «впиши «с» или «к»» → варианты из кавычек (только когда все токены в кавычках короткие); пропуск из двух подчеркиваний `__`; кириллические ответы допустимы в type/choice.
- `STU_VERSION = 4` — страницы учеников пересоберутся при ближайшей синхронизации.

Итог: фикстура fr.md — 7 упражнений, 52 задания, все 52 — выбор. Курс: выбор 58%, впиши 2%, брак 0. Как Маргарите оформлять страницы, чтобы все конвертировалось: скилл «notion-exercise-to-app» (предложен 24.11).

## Ключ — целое предложение, в задании пропуски (25.11.2026)

Страница «J'aime lire против j'aime la lecture (A1)» показывалась через «Показать ответ»: ключ к «Je ... (aimer) lire.» — целое «J'aime lire.», а не слово в пропуск. Добавлено:
- `alignGaps(qText, whole)` — ответ пропуска вырезается из целого ключа по окружению; элизия (je → j', ne → n') уходит в ответ («J'aime»); соседние пропуски, разделенные только подсказкой, сливаются в один ответ.
- `frVerbDistractors` — неверные формы французского глагола из подсказки «(aimer)»: другие окончания (-es, -ent…), снятая элизия («Je aime»), «ne pas aime». Один пропуск → выбор; несколько → сборка из слов с ловушками (в т.ч. из «(le / la / без артикля)»).
- «Найди и исправь ошибку» без ❌/✅: ключ «Верно.» → кнопки «Верно, ошибки нет / Есть ошибка»; ключ «исправленное. - пояснение» → выбор из исправленного и исходного. Сравнение точное (дефис/апостроф различают «Est ce qu il» и «Est-ce qu'il»).
- Русские транскрипции в квадратных скобках «[эскиль]» вырезаются из ключа.
- Устные упражнения («прочитать вслух», «записать голосовое») в приложение не берутся, как и перевод.
- `STU_VERSION = 5`. Страница: 42 заданий, 18 выбор, 24 сборка, 0 «вспомни».

## Группы, чтение, французские глаголы (25.11.2026, вечер)

Страница «Чтение и фонетика с нуля (A0)»: «распределить слова по группам» и «какая буква не читается» шли как «Показать ответ». Добавлено: группы → по слову выбор группы (нормализатор, ключ «(о) - au / eau: auto (ото), …»); чтение → `readingChoice` (верное чтение из ключа после «;», неверные — «как если бы немая буква читалась» + подмена гласного); `FR_IRREG` для etre/avoir/aller/faire; основа глагола сравнивается без акцентов (préférer → préfère); ключ «предложение - пояснение» → ответ без пояснения, пояснение в подсказку. Все 4 французские страницы — 0 «вспомни». Таблица типов: [[формат адаптации упражнений из Notion для приложения]].

## Вечер 25.11: pick, чтения от того же слова, перевод, позиция (26.11.2026 ночью)

Требования Маргариты: перевод слова/предложения всегда (кроме заданий на перевод); больше пунктов; «выпиши/распредели» — кнопками собирать в списки; в заданиях на чтение не давать чтения чужих слов; «назови правило» — не брать; названия короче; после ответа все на одном экране; возвращать на место остановки.
- Новый тип `pick` (выбери несколько): `[выбери] label: a / b / c` из нормализатора (подмножество, группы), в приложении плитки + «Проверить».
- `readingWrongs(word, reading)` — неверные чтения того же слова; `sib` остается только для нечитальных ответов.
- Перевод: «robe (платье) — …» и «предложение. (Перевод.)» → `d.tr`, показывается под заданием; нормализатор и pick сравнивают слова без скобок.
- «Впиши сама / по памяти / без вариантов» в названии → `type` (печатать), `src: "typed"`.
- Приложение: `posSet`/`last` в progress — возврат в тему, упражнение и задание после выхода; название упражнения без «Упражнение N.»; счетчик без повтора названия; «Дальше» прокручивается в экран.
- Страницы Маргариты-ученицы дополнены переводами (произношение, J'aime lire, отрицание 20.11, чтение 13.11), 3.2/5.3/6.3 расширены до 10–12 пунктов, создана «Числительные 1-10» (4 упражнения: выбор с чтением, цифра по слову, впиши сама, впиши в предложении). STU_VERSION = 6.

## Шаги по пропускам и неоднозначные слова в группах (26.11.2026)

- Несколько пропусков в пункте («Je ... (avoir, отрицание) ... (de / d') voiture.») — больше не «собери из слов», а шаги: сначала глагол (выбор форм), потом de / d' / артикль из скобок; заполненное видно жирным. Склеенные alignGaps пропуски разбиваются по вариантам в скобках следующих пропусков (`gapSteps`). Исправлен сдвиг позиции после элизии je → j' во втором пропуске.
- Группы «распредели по звуку»: слово с сочетаниями двух групп (beaucoup: eau и ou) не дается — иначе верный ответ ученика засчитывался ошибкой.
- Под заданием: перевод `(…)` и чтение `[…]` из пункта; кнопка «📝 В заметки» после ошибки; при пояснении из ключа случайный блок «Правило · теория» не показывается. STU_VERSION = 7.

## 26.11: проверка английских домашних (Павел, Станислав, Илья)
- Пропуски с ключом «stole / are checking» и «him, his» — по шагу на каждый пропуск, формы глагола как в боте.
- «Ответь на вопрос» с ключом «No, I haven't. …» — выбор короткого ответа: тот же вспомогательный, что в вопросе.
- «Найди ошибку»: ключ «Верно. пояснение», ключ-кусок без указания замены («She grumbles») — вклеивается в исходное предложение; если место не однозначно (перестановка слов) — сборка из слов.
- Задание «где верны оба — напиши «оба»» — у каждого пункта кнопка «оба».
- «оба» в пояснении («оба глагола в прошлом») больше не считается двумя верными ответами.
- Не даем неверным вариантом то, что тоже верно: must go / have to go, She read / was reading.
