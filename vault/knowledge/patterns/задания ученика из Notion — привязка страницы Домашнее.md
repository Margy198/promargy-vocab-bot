# Задания ученика из Notion — привязка страницы Домашнее

Запрос Маргариты 17.11: связать страницу Notion и аккаунт ученика в боте, чтобы упражнения из Notion становились упражнениями в приложении.

## Как работает
- Привязывает **только преподаватель**: Кабинет → карточка ученика → «📒 Задания из Notion» → вставить ссылку на страницу «Домашнее» ученика (или на страницу ученика: тогда берется подстраница «Домашнее…»). Действия `notionLink` / `notionUnlink` — только админ. Прав доступа привязка не дает и не меняет.
- Фоновая функция `course-rebuild-background`, режим `student`: читает подстраницы (до 60 последних, страницы «для преподавателя» пропускает, хвост «(1)» в названии убирает), неизмененные страницы не перечитывает (`last_edited_time`).
- `netlify/lib/homework-normalizer.mjs` приводит свободный формат домашки к шаблону курса, дальше работают те же `buildTopic` и `buildTopicDrills`. См. [[интерактивные задания строятся из ключа Маргариты]].
- Blobs `vocab-bot-course`: `stu:<chatId>:link`, `:index`, `:status`, `:topic:<id>`.
- Ученик: «Учеба → 📒 Мои задания» (категория `mine`, новые страницы сверху). Видит только свои страницы. «Тема пройдена ✓» работает как в курсе. Если список старше 30 минут, приложение само просит перечитать Notion.

## Дата, уведомление, ошибки (18.11, вечер)
- **Дата материала.** У каждой страницы берется дата создания в Notion (`created_time`). В списке «Мои задания» она стоит перед числом упражнений, список отсортирован по ней (новые сверху), в шапке темы — «материал от ДД.ММ.ГГГГ».
- **Уведомление ученику.** Когда при очередном чтении в «Домашнем» появилась новая страница, бот пишет «📒 У тебя новое задание» / «У вас новое задание» (по настройке обращения) с кнопкой «Открыть задания» (`page=study&go=mine`). Первая сборка — без сообщений; страницы старше 7 дней — без сообщений. Путь: фоновая функция кладет `stu:<id>:notify` и дергает `GET /telegram-webhook?stunotify=<секрет>&chat=<id>`.
- **Ошибки в упражнениях.** Приложение шлет `courseMistakes` (вопрос, верный ответ из ключа, ответ ученика, счет упражнения); хранится в `mist:<chatId>` (до 40 тем, до 40 ошибок на тему). В кабинете в карточке ученика блок «Ошибки в упражнениях». Работает для всех тем курса и для «Моих заданий».
- Не привязаны к 18.11 активные ученики из базы «Ученики»: Алина, Илья, Мусалав, Павел, Дмитрий — список отправлен Маргарите на согласование, нужны их chat_id.

## Какие форматы страниц понимает
- Заголовок упражнения: «Часть N», «Упражнение N», «Задание N», Exercise / Part / Task — заголовком или жирной строкой.
- Ключ: тоггл «Ответы» / «Ключи — часть N» под упражнением; один общий тоггл «Ответы» с подзаголовками «Часть N»; раздел «## Ответы» в конце с подзаголовками.
- «N. ответ — пояснение по-русски» → ответ и пояснение (💡). «верно» → «ошибки нет».
- Текст до первого упражнения и тогглы вроде «Справка» → теория.
- С 18.11 ключ читается и простым текстом, не только в тоггле: строка «Ответы» / «Ключи» / «Answers» (обычная, жирная или заголовок) под упражнением или внизу страницы; «Ответы к упражнению 2»; ответы в одну строку («Ответы: 1. too 2. very»); «1)» вместо «1.»; ответы без номеров, по одному на строке; общий ключ без подзаголовков делится там, где нумерация начинается с 1. Фраза вроде «Ответы запиши в тетрадь» ключом не считается.
- Упражнение без ключа остается только для чтения, в журнале кабинета об этом строка.

## Что нужно от Маргариты
- В Notion открыть интеграции бота доступ к страницам учеников («•••» → «Подключения»). Без этого в кабинете будет ошибка «Notion не отдает эту страницу».
