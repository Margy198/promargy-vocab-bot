# Мои ошибки, отметка в Notion и напоминание накануне урока

Три функции, добавленные 24.11.2026 по решению Маргариты.

## «Мои ошибки» (ученик)
Карточка «🔁 Мои ошибки» на главной «Учебы» — видна, когда за 14 дней есть записанные ошибки (`mistakes14` в payload курса). API `myMistakes` отдает ошибки по темам (`mist:<chatId>`, 14 дней, до 12 тем по 20 заданий). Приложение (`openMistakes`) подгружает темы (`topic`, кэш), собирает синтетическую тему `id: "mistakes"` с заданиями `mist:<id>` (`_src`, `_topicId`, `_topicTitle`) и открывает тренировку (`view: "train"`). Ошибки в этой тренировке пишутся в исходную тему. «Назад» и «На главную» ведут на главную.

## Отметка «сделано» в карточке урока
`courseSet` со статусом `done` для задания из Notion → `markStudentTaskDone` → POST фоновой функции `{mode: "taskDone", chatId, topicId, title, ok, total}` (ok/total — сумма результатов упражнений из `mist:<id>.results`). Фоновая функция: страница ученика в базе «Ученики» (поднимаемся по родителям привязки, кэш `link.studentPageId`), последние 12 уроков из базы «Уроки» (`78ebeb3357284c02993e5ced3dc20c36`, relation «✨Ученики база данных»), ищем в «Домашнее» mention на страницу задания и дописываем в конец «✅ сделано в приложении 24.11, 12 из 15 верно»; существующие mention сохраняются (`rtClean`). Если урок не нашли — callout в саму страницу задания. Защита от повтора: `stu:<id>:done:<topic>`.

## Напоминание накануне урока
В базе «Уроки» нет будущих уроков — карточка создается после урока. Поэтому расписание выводится из последних уроков: если за 6 недель уроки были в завтрашний день недели хотя бы дважды — напоминаем в 19:07 МСК, время — самое частое для этого дня (дата урока в Notion в UTC, +3). Запуск: `student-notion-sync` в 16 UTC шлет `{mode: "lessonRemind"}`; фоновая функция пишет `stu:<id>:lesson` и дергает `GET ?lessonremind=<секрет>&chat=<id>`; вебхук шлет «📅 Урок завтра в 16:20. Не сделано заданий: 2 …» с кнопкой «Открыть задания» (или «все задания сделаны»). Не сделано = страницы за 21 день с упражнениями, у которых нет статуса done. Защита от повтора: `lessonremind:<дата>` со сводкой.

## 5 ошибок подряд
Экран был и раньше (`WRONG_RUN_LIMIT = 5`, `renderTheoryPrompt`); для страниц без теории (задания из Notion) теперь показывает правило из вводной к упражнению и одну кнопку «Продолжить».

Не проверено вживую: запись в реальную базу «Уроки» через API интеграции (права на редактирование страниц уроков), реальные уведомления.
