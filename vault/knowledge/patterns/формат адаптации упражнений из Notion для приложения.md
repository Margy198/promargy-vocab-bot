# Формат адаптации упражнений из Notion для приложения

Правило одно: каждый пункт в приложении — выбор кнопками. Правильный ответ всегда из ключа Маргариты, неверные варианты конвертер строит сам по правилам ниже. Если конвертер не может построить кнопки — это дефект конвертера, а не повод показать «Показать ответ».

## Типы упражнений и что получает ученик

| Тип упражнения в Notion | Как выглядит в приложении | Откуда неверные варианты |
|---|---|---|
| **Раскрыть скобки, один пропуск**: «Je ... (aimer) lire.», «I ... (go) to work.» | Выбор формы: J'aime / J'aimes / J'aiment / Je aime | Английский: формы глагола (goes, went, going), слова подсказки, замены служебных слов (in/on/at, some/any). Французский: другие окончания (-es, -ent, -ons), снятая элизия (je aime), pas перед глаголом, другие формы etre / avoir / aller / faire |
| **Раскрыть скобки, два и больше пропусков**: «Je ... (aimer) ... (le / la) lecture.» | Сборка: плитки J'aime · la + ловушки J'aimes · le; ученик нажимает плитки по порядку | Формы глагола + варианты из скобок «(le / la / без артикля)» |
| **Пометка «отрицание»**: «Je ... (aimer, отрицание) cuisiner.» | Выбор: n'aime pas / n'aimes pas / ne aime pas / ne pas aime | Окончания, элизия, порядок pas |
| **Артикли**: «... apple», «He is ... engineer» | Выбор: a / an / the / без артикля (только тот набор, который тренирует упражнение) | Набор артиклей упражнения |
| **Варианты прямо в пункте**: «robe — роб / робэ», «(was / were)», «a) … b) …» | Кнопки из пункта, в том порядке, как в Notion | Ее же варианты |
| **Варианты в названии**: «HIS или HER?», «впиши «с» или «к»» | Кнопки из названия | Ее же варианты |
| **Найди и исправь ошибку** | Выбор из двух предложений: исправленное и исходное. Для верных пунктов: «Верно, ошибки нет / Есть ошибка» | Исходный пункт |
| **Поставь в отрицание / задай вопрос / перепиши** (ключ — целое предложение) | Сборка предложения из слов + ловушки (ne/n', pas, de/d') | Слова ключа + типовые ловушки |
| **Распредели слова по группам (колонкам)**: список через « / », ключ «(о) - au / eau: auto, beau, …» | По каждому слову выбор группы: (о) au, eau / (ё) eu / (у) ou / (уа) oi | Остальные группы |
| **Какая буква не читается + чтение**: «trop - …», ключ «не читается конечная p; тро» | Выбор чтения русскими буквами: тро / троп / тра | «Как если бы немая буква читалась» (троп, хистуар, гошэ) + подмена гласного (тхю, лю) |
| **Выбери верное чтение**: «Q - кю / кью» | Кнопки из пункта, после ошибки — пояснение из ключа | Ее же варианты |
| **Выпиши только те слова, где…**: список слов + ключ-подмножество | По каждому слову «да / нет» | — |
| **Список слов + ключ чтений через « / »**: «hisse / hippie …» и «ис / ипи …» | По слову выбор чтения, варианты — чтения соседних слов | Соседние ответы того же упражнения |
| **Условные обозначения** во вводной («У — умение, В — возможность») + ключ «У» | Кнопки с расшифровкой: Умение / Возможность / Просьба | Легенда |
| **Разделительные вопросы**, наречия от прилагательных, контраст времен | Выбор: верный хвостик / смена знака / чужой вспомогательный; slowly / slow / slowlyly; is doing / does | Правила английской грамматики в конвертере |

## Что в приложение не попадает

- **Перевод RU → EN** — по решению Маргариты не берем (ни упражнением, ни отдельными пунктами).
- **Устные задания** («прочитать вслух», «записать голосовое») — кнопками не сделать, остаются для урока.
- **Творческие** («расскажи о себе», «напиши 5 предложений») — показываются как пример для самопроверки, кнопок нет.

## Как оформлять страницу в Notion, чтобы все конвертировалось

1. Заголовок упражнения: «Упражнение N. Задание…» (или «БЛОК N.» + жирное «1.1. Задание»). В названии — суть задания: по нему конвертер понимает тип («найти и исправить ошибку», «распределить по группам», «раскрыть скобки»).
2. Пункты — нумерованным списком. Пропуск — «...» или «…».
3. Подсказка в скобках сразу после пропуска: «(aimer)», «(aimer, отрицание)», «(le / la / без артикля)», «(not / go)».
4. Варианты в пункте — через « / »: «robe — роб / робэ».
5. Ключ — в toggle «Ответы: упражнение N», нумерация как в задании. Форматы ключа, которые конвертер понимает:
   - слово или форма в пропуск: «aime»;
   - целое предложение: «J'aime lire.» (ответ пропуска конвертер вырежет сам);
   - предложение + пояснение по-русски после « - »: «Je n'aime pas lire. - в отрицании глагол остается»;
   - «Верно.» для пунктов без ошибки;
   - группы: «(о) - au / eau: auto (ото), beau (бо)»;
   - чтение: «не читается конечная p; тро» (чтение — после «;»);
   - транскрипции в квадратных скобках «[эскиль]» конвертер вырежет.
6. Два верных ответа — пометка «оба» в ключе; тогда пункт не станет выбором с одним правильным.
7. Пояснение по-русски в ключе показывается ученику только после неверного ответа.

## Как проверить страницу до ученика

В боте `/notion` — отчет синхронизации. В приложении открыть страницу в «📒 Задания из Notion»: все пункты должны быть с кнопками. Если где-то «Показать ответ» — прислать скриншот, это дефект конвертера.
