# Каждое задание из Notion — выбор кнопками, скилл конвертации

Маргарита увидела на французской странице задания 2.1–2.3 простым текстом и попросила: «каждое упражнение придумывать, как адаптировать, но важно, чтобы каждый раз можно было выбрать из вариантов (кнопками)», и сделать скилл по конвертации.

Сделано:
- Нормализатор понимает формат `## БЛОК N.` + `1.1. …` + `## КЛЮЧИ`, ключи-списки через « / », подмножество «выпиши только те» → «да / нет».
- Конвертер: варианты из пункта «X — a / b», из соседних ответов упражнения, из букв в кавычках в названии; пропуск `__`; кириллица в ответах.
- Исправлен брак: варианты из кавычек «if / whether / оба» давали русские слова при латинском ключе — теперь русские варианты только из коротких токенов в кавычках.
- `STU_VERSION = 4`. Линт: брак 0; выбор 58%.
- Скилл «notion-exercise-to-app» предложен через карточку (сохраняет Маргарита).
